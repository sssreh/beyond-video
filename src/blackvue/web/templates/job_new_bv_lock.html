Lock ranges (bv-lock)

Mark a time range in an already-configured camera's archive as already generated, so Generate assets skips it entirely on future runs instead of walking every recording in it again. A range stays skippable only for the asset types it was locked with - a later run asking for something not yet locked (a new asset type) is never blocked. See Generate assets's own Ignore lock option for the rare case of touching an otherwise-locked range again.
