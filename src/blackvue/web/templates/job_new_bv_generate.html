Generate assets (bv-generate)

Extracts audio, computes real-world duration, transcribes/ translates, and describes the scene for recordings in one camera's archive - the same actions bv-generate runs from the command line. See Describe scenes for the fuller set of scene-description tuning flags. Generated files are written next to their source recording and show up in the archive browser and bv-ls. Ranges already marked done via Lock ranges are skipped automatically unless Ignore lock (below) is checked.
